Étape 1 : Obtenir une clé d'API Google Gemini

  1. Ouvrez votre navigateur internet habituel.
  2. Rendez-vous sur la plateforme officielle : aistudio.google.com.
  3. Connectez-vous à l'aide de votre **compte Google**.
  4. Sur le tableau de bord, cliquez sur le bouton bleu **"Get API key"** (Obtenir une clé d'API) situé en haut à gauche.
  5. Cliquez sur **"Create API key"** puis validez sur **"Create API key in new project"**.
  6. Une suite de caractères cryptiques s'affiche (ex: AIzaSy...). Cliquez sur **"Copy"** pour la placer dans votre presse-papiers.

Étape 2 : Activer l'application sur votre PC

  1. Revenez sur cette application de création Cricut.
  2. Repérez le champ textuel en haut à droite (sous l'entête sombre) affichant : "Collez votre clé d'API Gemini ici...".
  3. Faites un clic droit dans ce champ puis choisissez **Coller**, ou utilisez le raccourci clavier Ctrl + V.
🔒 Sauvegarde automatique par PC :
Le navigateur internet retient cette clé de façon sécurisée locale (localStorage). Vous n'aurez besoin de faire cette manipulation qu'une seule fois par poste !

Étape 3 : Concevoir un motif avec l'IA

  1. Dans le champ de texte en bas à droite, écrivez précisément le dessin à fabriquer.
  2. Cliquez sur le bouton **Créer** ou validez via la touche **Entrée**.
  3. L'IA configure les tracés et l'aperçu vectoriel apparaît en direct à gauche de votre écran.
💡 Recommandations spécialisées Cricut :
Formulez vos demandes sous forme de silhouettes, contours de formes pleines ou styles épurés (ex: "Dessin de chat minimaliste"). Évitez les effets d'ombrages ou de micro-détails fins impossibles à couper pour la lame.

Étape 4 : Découpe sur Cricut Design Space

  1. Dès que le rendu vous convient, cliquez sur le bouton vert **Télécharger pour Cricut (SVG)**.
  2. Démarrez votre logiciel officiel **Cricut Design Space**.
  3. Ouvrez un nouveau canevas, cliquez sur **Télécharger** (Upload) > **Télécharger l'image** et chargez votre fichier `.svg`.
  4. Le fichier sépare automatiquement les éléments graphiques sur différents tapis selon leurs calques de couleurs d'origine.
