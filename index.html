Le plan de travail (façon Cricut Design Space)

  1. Formes / Texte / Images / IA : chaque élément ajouté apparaît comme un objet indépendant sur le plan de travail (en cm, comme un vrai tapis Cricut). Cliquez un objet pour le sélectionner, faites-le glisser pour le déplacer, et tirez les poignées d'angle pour le redimensionner.
  2. Texte : double-cliquez un texte sur le plan de travail pour le modifier.
  3. Couleurs : le code hexadécimal est lisible et modifiable directement (champ à côté du sélecteur). La pipette 🎯 prélève une couleur n'importe où à l'écran (nécessite Chrome ou Edge récent). Pour une image multicolore (importée, IA ou web), les couleurs détectées s'affichent en pastilles : cliquez-en une pour la remplacer par une autre, ou l'effacer complètement.
  4. Projets : le bouton 🚀 Projets permet d'enregistrer le plan de travail actuel sous un nom, et de rouvrir un projet sauvegardé plus tard. Les projets sont stockés localement dans ce navigateur (pas sur internet) — ils ne sont donc disponibles que sur cet appareil et ce navigateur.
  5. Pivoter : une petite poignée ronde apparaît au-dessus de tout objet sélectionné, reliée par un trait — faites-la glisser pour faire pivoter l'objet.
  6. Rogner : sélectionnez une image (importée, IA ou recherche web), cliquez l'outil ✂️ Rogner, ajustez le cadre vert puis validez.
  7. Formes modifiables : carré, rectangle, triangle, triangle rectangle, pentagone, hexagone, octogone, étoile, losange, flèche, bulle, nuage et cœur peuvent être déformées sommet par sommet. Double-cliquez la forme pour afficher ses points verts, puis glissez-les un par un. Double-cliquez à nouveau (ou Échap) pour quitter ce mode.
  8. Suppression : sélectionnez un objet puis touche Suppr/Retour, ou le bouton « Supprimer la sélection » en haut du plan de travail.
  9. Zoom : utilisez les boutons +/− en bas à droite du plan de travail.
  10. Images web : moteur de recherche Pixabay (6 millions+ d'images libres de droits : photos, illustrations, vecteurs). Nécessite une clé API gratuite obtenue sur pixabay.com/api/docs (sans CB). Filtres par type, pagination (40 images/page).
  11. Images (PNG, JPG, BMP, GIF) : à chaque import, une fenêtre vous demande de choisir entre un contour noir et blanc (silhouette de découpe) ou la conservation des couleurs d'origine.
  12. Fichiers DXF : l'outil décode la géométrie CAO et l'ajoute aussi comme objet déplaçable.
  13. Téléchargement : exporte l'intégralité du plan de travail (tous les objets, à leur taille réelle en cm) en un seul fichier SVG prêt pour Cricut Design Space.

Étape : Obtenir une clé d'API Google Gemini

  1. Rendez-vous sur : aistudio.google.com et connectez-vous avec votre compte Google.
  2. Lors de votre première visite, acceptez les conditions d'utilisation de l'API Generative AI si elles vous sont demandées.
  3. Dans le menu de gauche, cliquez sur « Get API key » (Obtenir une clé d'API).
  4. Cliquez sur le bouton « Create API key » (Créer une clé d'API).
  5. Choisissez « Create API key in new project » si vous n'avez pas encore de projet Google Cloud — Google s'occupe de tout créer automatiquement, aucune configuration cloud n'est nécessaire.
  6. Votre clé apparaît à l'écran, sous la forme d'une longue chaîne commençant par AIzaSy.... Cliquez sur l'icône de copie pour la copier.
  7. Collez-la directement dans le champ « Clé d'API Gemini » en haut de la fenêtre de chat de cet outil.
  8. Vérifiez que votre clé n'est pas marquée « Unrestricted » (non restreinte) sur la page des clés. Si c'est le cas, cliquez sur « Restrict key » puis sélectionnez « Restrict to Gemini API only » — depuis juin 2026, Google bloque les requêtes provenant de clés non restreintes.

⚠️ Cette clé est personnelle, ne la partagez avec personne. Le niveau gratuit de l'API Gemini permet de tester l'outil sans frais ni carte bancaire, dans la limite des quotas journaliers (voir la page tarifs d'AI Studio).
