Le plan de travail (façon Cricut Design Space)

  1. Formes / Texte / Images / IA : chaque élément ajouté apparaît comme un objet indépendant sur le plan de travail (en cm, comme un vrai tapis Cricut). Cliquez un objet pour le sélectionner, faites-le glisser pour le déplacer, et tirez les poignées d'angle pour le redimensionner.
  2. Texte : double-cliquez un texte sur le plan de travail pour le modifier.
  3. Couleurs : le code hexadécimal est lisible et modifiable directement (champ à côté du sélecteur). La pipette 🎯 prélève une couleur n'importe où à l'écran (nécessite Chrome ou Edge récent). Pour une image multicolore (importée, IA ou web), les couleurs détectées s'affichent en pastilles : cliquez-en une pour la remplacer par une autre, ou l'effacer complètement.
  4. Projets : le bouton 🚀 Projets permet d'enregistrer le plan de travail actuel sous un nom, et de rouvrir un projet sauvegardé plus tard. Les projets sont stockés localement dans ce navigateur (pas sur internet) — ils ne sont donc disponibles que sur cet appareil et ce navigateur.
  5. Pivoter : une petite poignée ronde apparaît au-dessus de tout objet sélectionné, reliée par un trait — faites-la glisser pour faire pivoter l'objet.
  6. Rogner : sélectionnez une image (importée, IA ou recherche web), cliquez l'outil ✂️ Rogner, ajustez le cadre vert puis validez.
  7. Formes modifiables : carré, rectangle, triangle, triangle rectangle, pentagone, hexagone, octogone, étoile, losange, flèche, bulle, nuage et cœur peuvent être déformées sommet par sommet. Double-cliquez la forme pour afficher ses points verts, puis glissez-les un par un. Double-cliquez à nouveau (ou Échap) pour quitter ce mode.
  8. Suppression : sélectionnez un objet puis touche Suppr/Retour, ou le bouton « Supprimer la sélection » en haut du plan de travail.
  9. Zoom : utilisez les boutons +/− en bas à droite du plan de travail.
  10. Images web (🔍 Pixabay) : 6 millions+ d'images libres de droits (photos, illustrations, vecteurs). Clé API gratuite sur pixabay.com/api/docs (sans CB). Filtres par type, pagination (40 images/page).
  11. Google Images (🌐 Google Img) : recherche sur Google Images via l'API Custom Search. Nécessite une clé API Google + un Search Engine ID — tous deux gratuits (100 req/jour). Voir l'onglet 🌐 Google Images de ce guide pour le pas à pas complet.
  12. Images (PNG, JPG, BMP, GIF) : à chaque import, une fenêtre vous demande de choisir entre un contour noir et blanc (silhouette de découpe) ou la conservation des couleurs d'origine.
  13. Fichiers DXF : l'outil décode la géométrie CAO et l'ajoute aussi comme objet déplaçable.
  14. Téléchargement : exporte l'intégralité du plan de travail (tous les objets, à leur taille réelle en cm) en un seul fichier SVG prêt pour Cricut Design Space.

Étape : Obtenir une clé d'API Google Gemini

  1. Rendez-vous sur : aistudio.google.com et connectez-vous avec votre compte Google.
  2. Lors de votre première visite, acceptez les conditions d'utilisation de l'API Generative AI si elles vous sont demandées.
  3. Dans le menu de gauche, cliquez sur « Get API key » (Obtenir une clé d'API).
  4. Cliquez sur le bouton « Create API key » (Créer une clé d'API).
  5. Choisissez « Create API key in new project » si vous n'avez pas encore de projet Google Cloud — Google s'occupe de tout créer automatiquement, aucune configuration cloud n'est nécessaire.
  6. Votre clé apparaît à l'écran, sous la forme d'une longue chaîne commençant par AIzaSy.... Cliquez sur l'icône de copie pour la copier.
  7. Collez-la directement dans le champ « Clé d'API Gemini » en haut de la fenêtre de chat de cet outil.
  8. Vérifiez que votre clé n'est pas marquée « Unrestricted » (non restreinte) sur la page des clés. Si c'est le cas, cliquez sur « Restrict key » puis sélectionnez « Restrict to Gemini API only » — depuis juin 2026, Google bloque les requêtes provenant de clés non restreintes.

⚠️ Cette clé est personnelle, ne la partagez avec personne. Le niveau gratuit de l'API Gemini permet de tester l'outil sans frais ni carte bancaire, dans la limite des quotas journaliers (voir la page tarifs d'AI Studio).

🌐 Google Images — Configuration pas à pas

Deux clés sont nécessaires : une clé API Google et un Search Engine ID (cx). Les deux sont gratuites et ne nécessitent pas de carte bancaire (quota : 100 recherches/jour).

Étape 1 — Activer l'API Custom Search

  1. Allez sur console.cloud.google.com et connectez-vous avec votre compte Google.
  2. En haut de la page, cliquez sur le sélecteur de projet puis « Nouveau projet ». Donnez-lui un nom (ex : Cricut Image Search) puis cliquez « Créer ».
  3. Dans la barre de recherche en haut, tapez « Custom Search API » et cliquez sur le résultat correspondant.
  4. Cliquez sur le bouton bleu « Activer ».

Étape 2 — Créer la clé API

  1. Dans le menu de gauche, allez dans API et services → Identifiants.
  2. Cliquez « + Créer des identifiants » puis choisissez « Clé API ».
  3. La clé s'affiche sous la forme AIzaSy…. Copiez-la.
  4. Collez-la dans le champ « Clé API Google » du panneau 🌐 Google Img.

⚠️ Si vous avez déjà une clé Gemini (AI Studio), elle ne fonctionnera pas ici — Custom Search est une API distincte qui nécessite sa propre clé créée dans Google Cloud Console.

Étape 3 — Créer le moteur de recherche (Search Engine ID)

  1. Allez sur programmablesearchengine.google.com et connectez-vous.
  2. Cliquez « Ajouter » (ou « Get started »).
  3. Dans le champ « Sites à rechercher », entrez * (astérisque) pour rechercher sur tout le web.
  4. Donnez un nom à votre moteur (ex : Google Images Cricut).
  5. Cliquez « Créer ».
  6. Sur la page suivante, cliquez « Personnaliser » (ou le nom de votre moteur dans la liste).
  7. Dans l'onglet « Fonctionnalités », activez le bouton « Recherche d'images » (Image search). Sans cela, aucun résultat d'image ne sera retourné.
  8. Revenez à l'onglet « Vue d'ensemble » et copiez le champ « Identifiant du moteur de recherche » (format : 123456789012345678901:xxxxxxxxxxxx).
  9. Collez-le dans le champ « Search Engine ID · cx » du panneau 🌐 Google Img.

Étape 4 — Utiliser le panneau

  1. Cliquez sur le bouton 🌐 Google Img dans la barre d'outils à gauche.
  2. Entrez votre clé API et votre Search Engine ID dans les champs (ils sont mémorisés automatiquement pour les prochaines sessions).
  3. Tapez votre recherche (ex : papillon monarque) et appuyez sur Entrée ou 🔍.
  4. Cliquez une image pour l'ajouter directement sur le plan de travail.

✅ Quota gratuit : 100 recherches par jour, sans CB. Au-delà, Google facture 5 $ pour 1 000 requêtes supplémentaires.

Demander un motif vectoriel

  1. Décrivez précisément votre idée (ex: *Silhouette de tortue marine épurée*). Le résultat est ajouté comme nouvel objet sur le plan de travail, déplaçable et redimensionnable comme les autres.

Générer une image réaliste (🖼️ Image)

  1. Saisissez votre description dans le chat, puis cliquez sur le bouton 🖼️ Image (violet) au lieu de « ✏️ Créer ».
  2. L'image est générée par Pollinations.ai (moteur FLUX) — entièrement gratuit, sans clé API, sans inscription. Nécessite uniquement une connexion internet.
  3. La génération prend environ 10 à 30 secondes.
  4. L'image générée (PNG) s'ajoute sur le plan de travail comme n'importe quelle image importée.
  5. Exemple : « Carte de la Guadeloupe avec les îles, style aquarelle » → cliquez 🖼️ Image.
