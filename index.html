Étape 1 : Obtenir une clé d'API Google Gemini

  1. Rendez-vous sur : aistudio.google.com.
  2. Connectez-vous avec votre compte Google.
  3. Cliquez sur **"Get API key"** en haut à gauche, puis générez une clé.
  4. Copiez le code fourni.

Étape 2 : Activer l'application

  1. Collez la clé dans le champ prévu en haut à droite.
🔒 Sauvegarde automatique : La clé reste enregistrée de façon sécurisée sur ce PC. Vous n'aurez plus à la remettre lors de vos prochaines visites.

Étape 3 : Demander un motif vectoriel

  1. Décrivez votre idée en bas à droite (ex: "Silhouette de tête de chat minimaliste, tracés pleins") puis cliquez sur **Créer**.

Étape 4 : Découper

  1. Une fois le rendu affiché à gauche, cliquez sur le bouton vert pour télécharger le `.svg`. Ouvrez-le directement dans **Cricut Design Space**.
